# Vehicle CLI

An interactive command-line application for creating and managing vehicles (Cars, Trucks, Motorbikes). Built with TypeScript and Inquirer.js, it lets you:

- **Create** new vehicles  
- **Select** an existing vehicle  
- **Perform actions**: start, accelerate, turn, tow, wheelie, print details, and more  

---

## 📦 Prerequisites

- [Node.js](https://nodejs.org/) ≥ 14  
- [npm](https://www.npmjs.com/) (bundled with Node.js)  

---

## 🚀 Installation

```bash
# Clone the repo
git clone <https://github.com/leviking12/vehicle-creator>
cd <vehicle-creator>

# Install dependencies
npm install
